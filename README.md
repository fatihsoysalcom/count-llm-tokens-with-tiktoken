# Count LLM Tokens with Tiktoken

This example demonstrates how to count tokens in text using the `tiktoken` library, which is used by OpenAI's Large Language Models (LLMs). Understanding token counts is crucial for managing token budgets in AI applications, as discussed in the accompanying article. The script shows how different lengths and types of text consume varying numbers of tokens.

## Language

`python`

## How to Run

1. Install the required library: `pip install tiktoken`
2. Run the script: `python main.py`
